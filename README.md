# Группы интересов в законодательном процессе: механизмы влияния на регулятивное содержание законопроектов в Государственной Думе РФ VI–VII созывов

Репозиторий содержит материалы к дипломной работе, посвященной анализу влияния групп интересов на изменение содержания законопроектов в Государственной Думе Российской Федерации.

Работа состоит из двух частей: сбор и обработка данных с расчетом косинусной близости между текстами законопроектов и итоговых законов, а также инференциальный анализ влияния групп интересов на изменение законопроектов.

## Структура репозитория

```
Thesis-Paper/
├── 02_modeling.ipynb         # EDA и Бета-регрессии
├── config.py                 # Конфигурация пайплайна (параметры, пути, таймауты)
├── cli.py                    # CLI-интерфейс для запуска стадий пайплайна
├── run_pipeline.py           # Обертка для последовательного запуска всех стадий
├── stage1_collect_urls.py    # Стадия 1: сбор URL законопроектов с sozd.duma.gov.ru
├── stage2_collect_documents.py   # Стадия 2: извлечение ссылок на входные и итоговые документы
├── stage2_5_patch_missing.py     # Стадия 2.5: дозагрузка пропущенных документов
├── stage34_autorun_simple.py     # Стадии 3+4: загрузка текстов и расчет эмбеддингов (простой запуск)
├── stage34_supervisor.py         # Стадии 3+4: то же с автоматическим перезапуском при ошибках
├── stage4_embeddings.py      # Стадия 4: ruBERT-эмбеддинги и косинусная близость
├── stage5_metadata.py        # Стадия 5: обогащение результатов метаданными карточек законопроектов
├── io_utils.py               # Утилиты ввода-вывода (CSV, JSONL, JSON)
├── logging_utils.py          # Настройка логирования
├── text_quality.py           # Эвристики качества текста (детекция мусорных извлечений)
├── clean_texts_jsonl.py      # Очистка texts.jsonl от поврежденных записей
└── requirements.txt          # Зависимости проекта
```
